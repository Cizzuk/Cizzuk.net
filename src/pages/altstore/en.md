# {{ title }}

Adding the [Cizzuk Source](https://altstore.io/source/i.cizzuk.net/altstore/source.pal.json) to AltStore PAL allows you to install my apps from it.

To use AltStore PAL, alternative app distribution must be available on your device.

[About alternative app distribution - Apple Support](https://support.apple.com/en-us/118110#availability)

## If you don't have AltStore PAL

Install AltStore PAL first to install apps from my source.

[Install AltStore PAL](https://altstore.io/download)

## If you already installed AltStore PAL

Here are the ways you can add the source:

1. Find "Cizzuk Source" in the "Popular Apps" collection within the AltStore PAL app
2. Open AltStore PAL using the following link: [Cizzuk Source](altstore-pal://source?url=https://i.cizzuk.net/altstore/source.pal.json)
3. Enter the following URL in AltStore PAL: `i.cizzuk.net/altstore/source.pal.json`

Once you have access to the source, you can install my apps.
