{% set sidesearch = collections.projects.sidesearch %} {% set sidesearch = { title: sidesearch.title, icon: sidesearch.icon, url: sidesearch.url } %} {{ AppBox(sidesearch, "h2", lazy=true) }}

The first app that lets users choose which voice assistant to use with the Side Button.

{{ LearnMoreLink(sidesearch.url) }}

Use Side Button Access, available only on iPhones in Japan, to set a voice assistant other than Siri to launch from the Side Button. The assistant can be powered by Claude, Gemini, web URLs, app URL schemes or a custom server.

{% set cbnote = collections.projects.cbnote %} {% set cbnote = { title: cbnote.title, icon: cbnote.icon, url: cbnote.url } %} {{ AppBox(cbnote, "h2", lazy=true) }}

Don't use the camera? Replace Camera Control with features like notes, a clipboard manager, or voice recording.

{{ LearnMoreLink(cbnote.url) }}

It's mostly a note app, but it is also a camera app that can be assigned to the Camera Control. In app settings, another action can be assigned to the Camera Control.

{% set alare = collections.projects.alare %} {% set alare = { title: alare.title, icon: alare.icon, url: alare.url } %} {{ AppBox(alare, "h2", lazy=true) }}

Do you accidentally dismiss the snooze or fall back asleep? Here is an alarm app that won't stop until you move your body.

{{ LearnMoreLink(alare.url) }}

Powered by AlarmKit, it doesn't need to stay open overnight, unlike many other alarm apps. That means less battery impact and no need to remember to open the app before bed.
