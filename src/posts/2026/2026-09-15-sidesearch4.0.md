- Added support for some features available on iOS 27 and later
- Increased the minimum OS requirement to iOS 27
- Added Private Cloud Computing as an option for Apple Foundation Models
  - Private Cloud Computing may be removed in the future
  - Added reasoning level settings for supported models in Apple Foundation Models
- Added the Claude API as a new assistant
  - You can use supported models with your own API key
  - Available as a beta version, so there may be bugs
- Added sidebar support
  - Moved the assistant list to the sidebar
- Updated the app icon
- Dismissed notifications from the Notification Center after using the assistant in the background
- Fixed an issue where new chats would no longer be saved if there was too much chat history
- Made some other adjustments

Update is available on the [App Store]({{ collections.projects.sidesearch.links.appstore }}) and [AltStore PAL]({{ site.links.altstore }}).
