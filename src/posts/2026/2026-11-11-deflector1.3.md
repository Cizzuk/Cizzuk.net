- Added a timer feature
  - Schedules a shortcut to run after a specified amount of time
  - Added shortcuts for timers
- Added support for text "Input" when running a shortcut from Apple Watch
  - To use this, you need to update Deflector Automation to the latest version
  - You can now choose a "Type" in the shortcut that adds a favorite shortcut
- Added caching for shortcuts fetched from your devices
- Deflector Automation now prompts you to update when needed
- Made some other adjustments

Update is available on the [App Store]({{ collections.projects.deflector.links.appstore }}) and [AltStore PAL]({{ collections.projects.deflector.links.altstore }}).
