- Added support for some features available on iOS 27 and later
- Made it easier to close the Quick Search Engine edit screen
- Errors no longer occur in Quick Search Engine editing even if keys are duplicated, or if a key or search URL is empty
  - If keys are duplicated, a unique key that avoids the duplication is automatically assigned
- Added an advanced setting to prevent custom search engine settings from being updated from shortcuts
- Updated the app icon
- Made some other adjustments

Update is available on the [App Store]({{ collections.projects.cse.links.appstore }}) and [AltStore PAL]({{ site.links.altstore }}).

- iOS 27以降で利用可能な一部の機能に対応しました
