- Added models available in the Claude API
  - Up to Fable 5.1
  - Up to Opus 5.5
  - Up to Sonnet 5.5
  - Up to Haiku 5.5
- Changed the default model of the Claude API to Opus 5.5
- Updated Search URL Presets
  - Changed 百度AI搜索 to 百度文心助手
  - Added Duck.ai
  - Removed Gemini
- Fixed an issue where the device's Auto-Lock was not disabled during speech recognition
- Fixed an issue where the URL Based Assistant could not search correctly when specific symbols were included in the search query
- Improved stability of Chat History and speech recognition features
- Made some other adjustments

Update is available on the [App Store]({{ collections.projects.sidesearch.links.appstore }}) and [AltStore PAL]({{ collections.projects.sidesearch.links.altstore }}).
