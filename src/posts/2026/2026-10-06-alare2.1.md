- Added partial support for iPhone Duo
- The Live Activity for wake-up actions now displays the current snooze count
- Added the time of the next alarm while snoozing
  - This is not displayed when Hard Mode is on
- Prevented the "Wave Device" action from continuing while the screen is open on iPhone Duo
- Changed the Live Activity text color to make it easier to read
- Made some other adjustments

Update is available on the [App Store]({{ collections.projects.alare.links.appstore }}) and [AltStore PAL]({{ site.links.altstore }}).
