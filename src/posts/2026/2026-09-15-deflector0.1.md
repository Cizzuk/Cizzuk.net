With Deflector, you can add buttons to the Dynamic Island and Lock Screen to run any shortcut.
You can long-press the Dynamic Island to quickly run shortcuts.

On supported iPhones in Japan, you can use your preferred voice assistant via shortcuts using the Side Button.

To use Deflector, you need to set up an automation in the Shortcuts app. The automation is available within the app.

Available on the [App Store]({{ collections.projects.deflector.links.appstore }}) and [AltStore PAL]({{ site.links.altstore }}).

<details lang="ja">
<summary>日本語</summary>

Deflectorを使えば、Dynamic Islandやロック画面に、任意のショートカットを実行するためのボタンを追加できます。
Dynamic Islandを長押しして、すぐにショートカットを実行できます。

対応する日本のiPhoneでは、サイドボタンからショートカットを通して、お好きな音声アシスタントを利用できるようになります。

Deflectorを使用するには、専用のオートメーションをショートカットアプリで設定する必要があります。オートメーションはアプリ内で入手できます。
