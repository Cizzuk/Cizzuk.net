- Added support for folders
  - You can create folders and add notes to them
- The current location is now shown in the navigation bar
- Changed all Camera Control actions except "Launch Camera" to be represented as URLs
- Removed the note list animation
- Changed the app icon
  - The old icon is available as "OG"
- Updated the Pride and Unity icons
- Made some other adjustments

Update is available on the [App Store]({{ collections.projects.cbnote.links.appstore }}) and [AltStore PAL]({{ collections.projects.cbnote.links.altstore }}).
