- Added support for iPhone Duo
- Added Apple Watch app
  - You can run shortcuts on your iPhone from your Apple Watch
  - You can also run shortcuts from complications or the Smart Stack
  - Added shortcuts to change Apple Watch settings
- Added settings to customize the Dynamic Island display for Live Activity
- Tapping a Live Activity now opens the Live Activity settings
- Added shortcuts to import and export Live Activity settings in JSON format
- Added controls to start and end the Live Activity
- Changed the default shortcut icon
- Made it possible to get a direct download link for an automation file by long-pressing the "Get Deflector Automation" button
- Added URL schemes
- Hide the "Side Button" setting on known unsupported devices
- Fixed some issues
- Made some other adjustments

Update is available on the [App Store]({{ collections.projects.deflector.links.appstore }}) and [AltStore PAL]({{ site.links.altstore }}).
