- Added support for some features available on iOS 27 and later
- Added "Wake-up Check" as a beta feature
  - Sends a notification a while after completing the Wake-up Action to verify if you are actually awake
  - If wake-up is not confirmed through the notification, the alarm will sound again
- Updated the app icon
- Fixed an issue where the snooze interval could not be set to more than 16 minutes
- Made some other adjustments

Update is available on the [App Store]({{ collections.projects.alare.links.appstore }}) and [AltStore PAL]({{ site.links.altstore }}).
